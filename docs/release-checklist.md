# 공개 전 점검표

2026-11-20 조사에서 나온 항목이며 법률 자문이 아니다. 법령 조문은 원문과 대조하지 못했으므로 조문이 나오는 줄마다 "원문 확인 필요" 를 붙였다. 코드 검증을 통과했다고 외부 승인이나 운영 점검이 끝난 것으로 보지 않는다. 확인이 끝난 항목만 직접 체크한다.

## 공개를 막는 항목

외부 승인이나 소유자 확인이 끝나야 공개할 수 있는 항목이다.

- [ ] 음원, 영상, 이미지 사용 권한을 확인한다(기존 MV 표시 옵션 포함).
  - [ ] 가수와 소속사 이용 허락이 필요한지, 비공식 팬 게임 고지, 재킷 등 이미지 권리.
  - [ ] 의존 라이브러리, 폰트, 이미지 라이선스 고지.
- [ ] 개인정보 처리방침, 계정 삭제 절차를 확인한다(재가입 차단 고지 포함). 탈퇴 뒤 식별자 보존과 고지 문구의 적법성은 옮겨 적지 않고 [`docs/pocketbase-operations.md` "운영 적용 전 승인 필요 항목"](pocketbase-operations.md#운영-적용-전-승인-필요-항목)을 따른다.
  - [ ] 처리방침이 개인정보 보호법 제30조 필수 항목(처리 목적, 보유 기간, 파기 절차, 처리위탁, 정보주체 권리, 보호책임자 연락처, 자동 수집 장치)을 담는지(원문 확인 필요).
  - [ ] 처리방침이 YouTube API 서비스 사용, Google 개인정보처리방침 링크, 쿠키와 localStorage 사용을 밝히는지.
  - [ ] 처리방침과 탈퇴 안내가 Google 로그인으로 저장되는 이름, 아바타를 밝히는지(운영 `users` OAuth 필드 매핑 확인 포함).
  - [ ] 서버가 해외 리전이면 국외 이전 근거와 고지(제28조의8, 원문 확인 필요).
  - [ ] 만 14세 미만 처리 방식 결정(가입 제한 또는 법정대리인 동의, 제22조의2, 원문 확인 필요).
  - [ ] 탈퇴 뒤 재가입 차단용 식별자 보관이 제21조 파기 의무와 맞는지 개인정보보호위원회 상담 또는 법률 검토(원문 확인 필요).
- [ ] 소유자가 확인한 개인정보 처리방침 주소를 정한다.
      현재 값: 주소 없음. `.env` 의 `VITE_PRIVACY_POLICY_URL` 을 채우면 CREDITS 에 PRIVACY 가 보인다.
- [ ] 문의처와 버그 제보 채널을 확인한다.
      현재 값: `https://github.com/DEV-asdf-516/dazbeat/issues` 로 소유자가 정했고 CREDITS 의 CONTACT 로 연결된다.
- [ ] Google OAuth 운영 환경과 HTTPS 도메인을 준비한다.
  - [ ] 운영 도메인 확보와 Search Console 소유 확인. 홈페이지와 처리방침을 같은 도메인에 둔다.
  - [ ] 동의 화면 프로덕션 게시와 브랜드 인증. 미인증 앱의 신규 사용자 100명 상한은 게시 상태와 요청 범위에 따라 달라지므로, 이 앱의 범위에서 적용되는지 Google 문서로 확인한다.
  - [ ] 동의 화면에 넣는 홈페이지, 개인정보 처리방침, 이용약관 링크 요건.
- [ ] 게임물 등급분류 면제 요건 확인(게임산업법 제21조 제1항 제4호, 비영리, 원문 확인 필요). 시행령의 면제 범위와 신고 여부, 광고와 후원과 결제를 붙일 때 달라지는 점.

## 그 밖의 확인 항목

- [ ] YouTube 임베드 정책을 확인한다(기존 MV 표시 옵션 포함).
  - [ ] 플레이어 표시 크기 200x200px 이상.
  - [ ] MV 를 숨기는 표시 옵션이 보이지 않는 상태의 재생, 오디오와 비디오 분리 금지 조항에 걸리는지.
  - [ ] 임베드 요청의 Referer 를 억제하지 않는지(억제하면 오류 153).
  - [ ] 재생이 사용자 조작 뒤에 시작되는지.
  - [ ] 수록 영상의 임베드 허용, 연령 제한, Made For Kids 상태.
- [ ] 해외 접속자 대응 범위 결정(GDPR, COPPA, 원문 확인 필요).
  - [ ] YouTube 임베드가 로그인하지 않은 방문자에게도 Google 쿠키를 남긴다. 해외 접속자에게 동의를 받을지. `youtube-nocookie.com` 도 localStorage·IndexedDB 를 쓰고 재생 전에 Google 에 접속하므로 동의를 대신하지 못한다.
- [ ] 비밀값 커밋을 막는 secret scanning(pre-commit 또는 CI)을 둘지 결정. 지금은 `.gitignore` 만 막는다.
- [ ] 실제 로그인, 플레이, 기록 제출을 운영 환경에서 확인한다.
  - [ ] 개발용과 운영용 Google Cloud 프로젝트(OAuth 클라이언트)를 나눌지.
  - [ ] 리디렉션 URI 가 HTTPS 이고 IP 주소 호스트가 아닌지.
  - [ ] 두 탭에서 판을 시작했을 때 먼저 시작한 판이 미등록으로 안내되는지.
- [ ] PocketBase 접근 제어, 레이트 리밋, 백업과 복구는 옮겨 적지 않고 [`docs/pocketbase-operations.md` "운영 확인 체크리스트"](pocketbase-operations.md#운영-확인-체크리스트)를 따른다.
- [ ] 지원 브라우저에서 기본 플레이와 영상, 네트워크 오류 복귀를 확인한다.
  - [ ] 키보드가 없는 환경(모바일)을 지원 대상에서 뺄지와 그 안내 방법 결정.
  - [ ] 한국어, 일본어, 영어 각각에서 새 안내 문구가 잘리지 않는지.
- [ ] 배포 뒤 장애가 났을 때 이전 버전으로 되돌리는 절차.
- [ ] 리뷰 운영: 신고 접수 창구, 삭제 기준, 권리침해 삭제 요청 처리(정보통신망법 제44조의2 적용 범위 확인 포함, 원문 확인 필요).
- [ ] 이용약관 필요 여부와 내용 결정.
- [ ] 광과민성 주의 안내와 이펙트 줄이기 옵션을 둘지 결정.
